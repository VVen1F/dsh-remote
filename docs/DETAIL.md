# 局域网访问

在 DSH 自己的默认端口 **3080** 上提供局域网访问地址，手机扫二维码即可打开这台电脑上正在运行的 DeepSeek Harness。

## 它做什么

- 自动识别本机的局域网网卡与 IP，推荐最可能被手机访问到的那个地址。
- 在 `局域网地址:3080` 上监听，并把请求反向代理到本机 DSH 实际监听的端口，因此不需要改 DSH 主程序的任何配置。
- 生成与地址严格一致的二维码：地址变了，二维码立即重建。
- 多网卡（Wi-Fi、有线、虚拟网卡）时可手动切换，选择会保存下来，重启后继续使用。

## 它不做什么

- 没有公网隧道、没有域名管理。
- 没有微信 / QQ / 飞书 / Telegram 机器人。
- 没有额外的访问密码、Token、白名单或授权码：访问安全由 DSH 自己的登录机制负责。

## 使用

1. 确认电脑与手机连在同一个局域网（同一个 Wi-Fi 或同一台路由器）。
2. 打开 设置 → 局域网访问，等待状态变成「运行中」。
3. 用手机相机或浏览器扫描二维码。

## 端口说明

`3080` 是 DSH 的默认端口。如果 3080 在这台机器上已被别的程序占用，面板会直接说明原因，而不会偷偷换到别的端口或结束占用进程。
